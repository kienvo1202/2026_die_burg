German letter names are close to English, with a handful of traps:

| letter | sounds like | | letter | sounds like |
|---|---|---|---|---|
| **A** | "ah" | | **J** | "yot" |
| **E** | "ay" | | **Q** | "koo" |
| **I** | "ee" | | **V** | "fow" (rhymes with *cow*) |
| **G** | "gay" | | **W** | "vay" |
| **H** | "hah" | | **Y** | "ÜP-see-lon" |
| **U** | "oo" | | **Z** | "tset" |

**E and I are the big one:** German E sounds like the English letter A, and German I like the English letter E.

**To ask:** <Say de="Wie schreibt man das?" />. **To spell:** letter by letter, or with
a spelling alphabet on the phone (<span lang="de">*B wie Berlin*</span>).
