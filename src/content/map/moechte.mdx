*möchte* means "would like": the polite way to ask for something.

| | |
|---|---|
| **ich** | <Say de="ich möchte" /> |
| **du** | <Say de="du möchtest" /> |
| **er · sie · es** | <Say de="er möchte" /> |
| **wir** | <Say de="wir möchten" /> |

**Watch:** no *-t* for *er*: <Say de="er möchte" />, like *ich*.

**What it takes:** the thing you'd like is in the accusative (lesson 8):
<Say de="Ich möchte einen Salat." />

**Three ways to order** (lesson 9): <Say de="Ich nehme den Salat." /> ·
<Say de="Ich möchte einen Salat." /> · <Say de="Ich hätte gern einen Salat." />

**Still in the fog:** *möchte* with a second verb at the end (*Ich möchte zahlen*), and why
it has no *-t*: lesson 12.
