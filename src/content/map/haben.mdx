*To have* loses its *b* in the *du* and *er* forms:

| | |
|---|---|
| **ich** | <Say de="ich habe" /> |
| **du** | <Say de="du hast" /> |
| **er · sie · es** | <Say de="er hat" /> |
| **wir** | <Say de="wir haben" /> |
| **ihr** | <Say de="ihr habt" /> |
| **sie · Sie** | <Say de="sie haben" /> |

**Remember it by:** *thou hast*, *he hath*.

**What it takes:** the thing you have is in the accusative (lesson 8):
<Say de="Ich habe einen Bruder." /> <Say de="Wir haben keine Milch." />

**Still in the fog:** *haben* as a helper for the past (*ich habe gekauft*), later in A1.
