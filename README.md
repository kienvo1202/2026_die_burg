# Die Burg

A guided German course you read from start to finish: short lessons, each built around
one scene and one real insight into how German works. Styled as an illuminated
storybook, in the spirit of the Brothers Grimm, who collected fairy tales *and* began the
great German dictionary.

- **Now:** a static website (Astro), A1 lessons in progress.
- **Later:** iOS and Android apps built from the same code with Capacitor.

## Run it

Needs Node 22.22 or newer (see `.nvmrc`).

```bash
npm install
npm run dev        # http://127.0.0.1:4321
npm test
npm run check
npm run build
```
